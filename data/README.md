# Data

Raw and processed data are not committed to this repository (see `.gitignore`). This file documents where to get the raw data and how to lay it out so the pipeline runs unchanged.

## Source

NASA IMS Bearing Dataset (Center for Intelligent Maintenance Systems, University of Cincinnati), distributed via the NASA Prognostics Data Repository:
https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/

Download the "Bearing Data Set" archive and extract Set 1, Set 2 and Set 3.

## Expected layout

```
data/
├── raw/
│   ├── set1/   # Set 1 run-to-failure files
│   ├── set2/   # Set 2 run-to-failure files
│   └── set3/   # Set 3 run-to-failure files
├── processed/  # generated by the pipeline (parquet/csv/duckdb caches)
└── external/   # any external reference data, if used
```

Each `raw/set*/` folder should contain the dataset's original per-interval ASCII vibration files, unmodified and unrenamed, exactly as extracted from the NASA archive.

## Regenerating `data/processed/`

`data/processed/` is pipeline output, not source data. Running the pipeline from `src/main.py` onward against a populated `data/raw/` regenerates it.
